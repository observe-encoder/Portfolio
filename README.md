# ✦ Portfolio

> **Less, but better.**

A minimal, elegant and interactive portfolio website focused on **visual simplicity, smooth motion and thoughtful user experience**.

The idea is simple:

**Remove everything unnecessary and leave only what matters.**

---

## ✦ Philosophy

This portfolio is built around a simple design philosophy:

- **Minimalism** — nothing unnecessary.
- **Clarity** — content speaks for itself.
- **Motion** — animations feel natural and intentional.
- **Consistency** — every interaction follows the same visual language.
- **Details** — small interactions create the overall experience.

> Good design is not about adding more.  
> It's about knowing what to remove.

---

## 🎨 Design

The visual language is intentionally restrained.

### Typography

Large headlines.  
Short descriptions.  
Plenty of breathing room.

The goal is to make the interface feel **calm, premium and effortless**.
